# Figure 6: geographic and mitochondrial-cluster associations

Current entry point: `03_run_Figure6_associations.R`.

```bash
Rscript scripts/08_geo_mtlineage/03_run_Figure6_associations.R \
  "$LD_PRUNED_TSV" \
  scripts/08_geo_mtlineage/inputs/freshwater19_metadata.tsv \
  scripts/08_geo_mtlineage/inputs/OXPHOS72_genes.list \
  "$FIGURE6_OUT" 9999
```

All panels use 19 long-term freshwater populations, excluding AMO and all five recent populations. No PC input is required.

A compares a quasibinomial latitude/longitude model against an intercept-only model.
B compares a quasibinomial mitochondrial-cluster model against an intercept-only model. Neither SNP model includes treePC covariates. B therefore measures unadjusted association and cannot distinguish mitochondrial-cluster effects from shared nuclear population structure. Its effect size is the range of fitted cluster frequencies.

Nonconverged models are excluded from P-value correction and candidate counts. Model warnings/status counts are saved to model_diagnostics.tsv. BH correction is separate for A and B; candidates require q<0.05 and effect>=0.20.

C retains within-gene multiple-SNP signed deltaAF profiles, with cluster labels permuted within region. It does not residualize treePCs. A separate cross-gene profile test selects one SNP per gene without using cluster labels.

Input must already be LD-pruned. Packages: data.table, ggplot2, ggrepel. Outputs include Figure6_ABC_unadjusted.pdf/png, SNP models, gene summaries, profile tests, model counts and diagnostics. Real-data results must be rerun; old candidate counts are not guaranteed to match.

Other scripts, including 03_run_treePC_controlled_Figure6.R, are historical alternatives. Existing archived tables and Figure S9 are not regenerated by installing this script.
